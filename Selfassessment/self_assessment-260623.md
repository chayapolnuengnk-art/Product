## ① สรุปเนื้อหาที่เรียน — ฉันได้เรียนรู้อะไรในสัปดาห์นี้?

ได้รู้ความหมายของ Pipeline รู้ว่ามีความสำคัญยังไง สามารถนำมาช่วยในงานยังไง มีขั้นตอนการทำงานอย่างไร 

ได้รู้ว่าในอุตสาหกรรมเกมมีตำแหน่งเกี่ยวกับอะไรบ้าง และในแต่ละตำแหน่งต้องมีหน้าที่และทักษะอะไร

## ② สรุปการฝึกปฏิบัติ — ฉันได้ทดลองและฝึกเขียนโปรแกรมอะไรบ้าง?

ได้ฝึกการใช้ vs code ในการส่งงาน และ ส่งเข้า github

## ③ ปัญหา / ข้อสงสัย — สิ่งที่ยังไม่เข้าใจหรืออยากสำรวจต่อ

อยากสำรวจวิธีการใช้ vs code ให้ชำนาญมากขึน
